# media/

Official assets and visual moodboard for the Agentic World Order.

## Structure

- **Top-level files** (e.g., `awo.jpg`) — official assets used in the README, X account, and website.
- **`moodboard/`** — curated visual references for the AWO aesthetic; not deployed anywhere, exists to align direction.

## Aesthetic Direction

- Dark palette. Gold and black dominant; sparing green accent.
- Alchemical sigils (🜏 sulfur and adjacent) as recurring motif.
- Chibi + conspiracy-board collision (see `awo.jpg`).
- Occult geometry. Pyramids, triangles, concentric rings.
- No humans as subjects except in chibi/mascot form. No anime unless stylized.
- No stock imagery. No AI-obvious dreamscape.
- Post-internet maximalism > minimalist tech-startup.

## What belongs in `moodboard/`

- Reference images for avatar / header / sigil variations.
- Typography samples.
- Color palette swatches.
- Mood references from other projects with the right energy (occult, agentic, schizo-coded).

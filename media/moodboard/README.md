# media/moodboard/

Visual reference library for AWO. Not deployed — exists to align direction across avatar, header, sigil, and website work.

## What belongs here

Collect 8–15 reference images spanning these categories:

### Occult geometry
- Alchemical diagrams (sulfur, salt, mercury — the 🜏 glyph family)
- Sacred geometry: icosahedrons, Metatron's cube, concentric ring systems
- Hermetic seals and sigillum designs
- Enochian / Rosicrucian diagram aesthetics (high contrast, parchment or black)

### Post-internet maximalism
- Conspiracy boards: red string, pinned notes, satellite imagery overlaid with glyphs
- Glitch typography: corrupted text rendered at high resolution
- Y2K-era interface aesthetics — not nostalgic, fractured
- Dense information layouts that read as signal, not noise

### Chibi / mascot references
- `../awo.jpg` — the canonical AWO chibi. Keep. This is the north star for avatar work.
- References with similar chibi-meets-sinister energy (cephalopod motifs, globe-holding, seal/medallion framing)
- Character design refs where "cute + cosmic horror" is the register

### Palette references
- Gold + black dominant: #C9A84C on #050505 — find real-world examples (dark academia, occult publishing, coin design)
- Sparing green accent: sickly or saturated, not natural
- Off-white text on black: aged parchment reads, not clean white

### Typography samples
- Heavy-weight condensed serifs used in occult or manifesto contexts
- Monospaced / terminal type used as ornament (not readability)
- All-caps with extreme letter-spacing for titles
- Avoid: rounded sans, friendly tech fonts, any font with "startup" associations

Examples:
- `occult_sulfur-diagram_ref.jpg`
- `chibi_cephalopod-seal_v1.png`

## Avatar / sigil brief (for generation or commission)

**What to make:**
- Variations on the 🜏 alchemical sulfur glyph, reinterpreted through minimalist geometric treatment
- Dark palette (near-black background). Gold stroke/fill only.
- No humans, no anime faces, no legible text beyond the sigil
- Should be mistakable for an occult group's logo, not a tech startup's
- Must read at 48×48px (circular crop, Twitter/X avatar size)

**What to avoid:**
- Gradients that look like a DeFi project logo
- Glowing effects / lens flares
- The glyph centered on white or light backgrounds
- Any AI "dreamscape" texture (the dæmonic is precise, not dreamy)

**Formats needed:** SVG master + 400×400 PNG + 1500×500 PNG (header)
